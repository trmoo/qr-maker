# 📱 QR 코드 만들기

**👉 <https://trmoo.github.io/qr-maker/> 에서 바로 쓸 수 있습니다.**

링크를 넣으면 QR 코드가 나오는 웹앱입니다. 글·Wi-Fi·연락처·전화·문자도 담을 수 있고,
QR 코드가 어떻게 만들어지는지 들여다보는 **수업용 화면**이 함께 있습니다.

* **인터넷이 없어도 됩니다.** 외부 라이브러리를 하나도 쓰지 않고 QR 인코더를 직접
  구현했습니다. 교실 인터넷이 끊겨도 그대로 씁니다.
* **담은 내용이 밖으로 나가지 않습니다.** 서버가 없습니다. 주소·연락처·와이파이
  비밀번호는 이 컴퓨터 안에서만 쓰이고 어디에도 저장되지 않습니다.

## 쓰는 법 (3줄)

1. 위 주소를 엽니다. (인터넷이 없는 교실이라면 `npm run build` 로 만든 `dist/index.html`
   한 파일을 USB 에 담아 가서 **더블클릭**해도 똑같이 됩니다)
2. 종류를 고르고 내용을 넣으면 오른쪽에 QR 코드가 바로 나옵니다.
3. **PNG**(화면·문서용) 또는 **SVG**(인쇄·확대용)로 내려받거나 바로 인쇄합니다.

## 화면

### ✨ QR 코드 만들기

| 종류 | 스캔하면 |
|---|---|
| 🔗 웹 주소 | 그 주소가 열립니다 |
| ✏️ 글 | 글이 그대로 보입니다 |
| 📶 Wi-Fi | 비밀번호를 치지 않고 바로 접속됩니다 |
| 👤 연락처 | 연락처에 저장됩니다 (vCard 3.0) |
| 📞 전화 | 전화 걸기 화면이 뜹니다 |
| 💬 문자 | 받는 번호와 내용이 채워진 문자 쓰기 화면이 뜹니다 |

꾸미기 — 오류 정정 수준(L·M·Q·H) · 칸 모양(각진 네모·둥근 네모·동그라미) · 색 ·
여백 · 내려받을 크기 · 투명 배경 · **가운데 그림(학교 로고)**.

**「이대로 스캔이 될까」를 함께 알려 줍니다.** 색의 밝기 차이가 모자라거나, 무늬가
바탕보다 밝거나(색을 거꾸로 쓴 상태), 여백이 좁거나, 로고가 너무 크면 **까닭과 함께**
짚어 줍니다. 아래쪽 「이 QR 코드의 속」에는 버전·부호화 방식·쓴 자리·인쇄 최소 크기가
나옵니다.

### 🔬 QR 코드 원리 — 「정보」 Ⅱ 데이터(부호화·오류 정정) 수업용

* **🧩 해부도** — 위치 찾기 무늬·타이밍·정렬·형식 정보를 색으로 가르고, 눌러 보면
  그것이 무슨 일을 하는지 설명이 나옵니다. 「29×29칸 가운데 실제 데이터는 몇 칸인가」도
  바로 보입니다.
* **🛡️ 오류 정정 체험** — 칸을 눌러 직접 가려 봅니다. 블록마다 몇 개까지 고칠 수 있는지
  막대로 보이고, 「아직 읽을 수 있습니다 / 이제 읽을 수 없습니다」를 판정합니다.
  빨간 표시를 숨기고 **휴대폰으로 화면을 찍어 보면 정말 읽힙니다.**
* **🎭 마스크 겨루기** — 여덟 가지 마스크의 벌점 네 가지(같은 색 줄·2×2 덩어리·
  가짜 찾기 무늬·검은 칸 치우침)를 나란히 보여 주고, 왜 그중 하나를 골랐는지 설명합니다.
* **🔢 담기는 과정** — 글 → 모드 고르기 → 비트 → 코드워드와 오류 정정 → 격자까지
  다섯 걸음으로 따라갑니다. 실제 코드워드 값이 16진수로 나옵니다.

## 개발

```bash
cd D:\project_AI\qr-maker
npm install
npm start        # 개발 서버 (http://localhost:5173)
npm run build    # dist/index.html 한 파일로 빌드 + 빌드 결과 점검
```

`main` 에 푸시하면 `.github/workflows/deploy.yml` 이 시험·점검·빌드를 돌려 GitHub Pages 에
올립니다. `dist/` 는 저장소에 넣지 않습니다.

### 점검

| 명령 | 하는 일 |
|---|---|
| `npm test` | 시험 499가지 — 아래 참고 |
| `npm run check:syntax` | 소스 전부 불러 보기 + 규칙 점검 + **앱을 실제로 한 번 그려 보기** |
| `npm run check:decode` | PNG 52장을 만들어 **다른 해독기(OpenCV)로 정말 읽히는지** |
| `npm run golden` | 기준 격자 다시 만들기 (segno · python-qrcode 필요) |

**`npm test` 가 지키는 것**

* 📐 **기준 대조 520가지** — 파이썬 `segno` 가 만든 QR 코드와 **모듈 한 칸까지** 같은지.
  버전 1~40 × 수준 L·M·Q·H × 마스크 8가지를 모두 돕니다.
* 🔀 **교차 대조 84가지** — `python-qrcode`(주류 구현)와도 맞대어 봅니다.
* 📏 규격 예제 — ISO/IEC 18004 의 `"01234567"` 코드워드, 형식 정보·버전 정보 비트,
  정렬 무늬 좌표, 버전별 담을 수 있는 최대 글자 수(숫자 7089 · 영숫자 4296 · 바이트 2953).
* 🖼 **SVG 가 격자와 한 칸까지 같은가** — 그림이 한 칸이라도 빠지면 안 읽히는데 눈으로는 모릅니다.
* 🖌 **그린 것이 격자와 한 칸까지 같은가** — 화면 미리보기와 PNG 내려받기가 쓰는
  `drawCanvas()` 를 가짜 캔버스에 그려 되읽어 맞대어 봅니다. 격자가 맞아도 **그리는 쪽**이
  틀리면 안 읽힙니다(실제로 위치 찾기 무늬가 뭉개진 적이 있습니다).
* 🛡 오류 정정 판정 · 종류별 담을 글(Wi-Fi 지운 뜻 바꾸기, vCard 줄 끝 CRLF 등).

## 알아 두면 좋은 것

* **종이에 인쇄할 때는 SVG** 를 쓰세요. PNG 는 크게 키우면 뭉개집니다.
* 담는 내용이 길수록 칸이 촘촘해집니다. 앱이 알려 주는 **인쇄 최소 크기**보다 작게
  만들지 마세요. 주소가 길면 짧은 주소로 줄이는 편이 훨씬 잘 읽힙니다.
* **색을 거꾸로 쓰지 마세요.** 밝은 바탕에 어두운 무늬여야 합니다.
* 가운데 그림을 넣으면 오류 정정 수준이 **H** 로 올라갑니다. 그래도 그림이 너무 크면
  안 읽히니 앱이 알려 주는 비율을 보세요.
* **만든 뒤에는 꼭 휴대폰으로 직접 찍어 확인**해 주세요.
